# FRONTLINE ZERO

If your goal is to build a shooter that's fun, fast, and realistic to complete as an indie project, avoid making an "exact" copy of any commercial game's mechanics. Instead, take inspiration from the feel—smooth movement, responsive gunplay, and a large map—while creating your own identity.

## Working Title

**FRONTLINE ZERO**

## Genre

* Multiplayer low-poly FPS
* Battle Royale + Extraction + Team Deathmatch
* HTML5 (Three.js + TypeScript + Vite)
* 60+ FPS on low-end PCs

---

## Core Pillars

* Fast, fluid movement
* Low-poly visuals with high readability
* Large seamless maps
* Easy to learn, difficult to master
* Runs on integrated graphics
* Instant matchmaking
* Sessions under 20 minutes

## Movement System

Inspired by the responsiveness of modern shooters, but with its own mechanics:

### Sprint

* Accelerates quickly
* Limited stamina only in certain modes

### Tactical Slide

* Short burst of speed
* Momentum carries downhill
* Can transition into crouch

### Vaulting

* Automatically clears waist-high obstacles
* Fast animations

### Mantling

* Climbs ledges smoothly
* Supports multiple heights

### Bunny Hop (Limited)

* Small momentum bonus
* Prevents infinite speed gain

### Leaning

* Peek around corners
* Smooth left/right transitions

### Dive

* Emergency prone movement
* Useful for dodging incoming fire

## Gunplay

Weapons are easy to identify and balanced by role rather than realism.

### Assault Rifles

* Reliable at medium range
* Moderate recoil

### SMGs

* Excellent mobility
* Strong in close quarters

### Marksman Rifles

* Accurate semi-auto fire
* Rewards precision

### Sniper Rifles

* High damage
* Slow handling

### Shotguns

* Devastating up close
* Limited effective range

### Sidearms

* Fast draw
* Backup weapon

## Technical Features

* Client-side prediction
* Lag compensation
* Interpolated player movement
* Object pooling
* Frustum and occlusion culling
* Level-of-detail (LOD) models
* Compressed network updates
* Optional FSR/DLSS-style upscaling where supported

---

## Unique Twist

Instead of a shrinking gas circle, the battlefield changes dynamically:

* Power stations go offline, disabling lights.
* Bridges can collapse, forcing new routes.
* Supply drones create temporary hotspots.
* Weather changes reduce visibility or affect sound.

This keeps matches feeling fresh without relying on a single shrinking-zone mechanic.

## Why this could stand out

Many low-poly shooters focus on either arcade chaos or realism. A game that combines polished movement, readable low-poly visuals, excellent performance, multiple game modes, and evolving maps could appeal to players looking for a lightweight competitive shooter that runs well on a wide range of hardware while still feeling modern.

## Playable Test (current milestone)

Status: **PLAYABLE** — run it and shoot targets.

```bash
npm install
npm run dev
```

Open the printed URL (default http://localhost:5173), click **CLICK TO DEPLOY**, and play.

### Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look |
| LMB | Fire (hold for automatic) |
| R | Reload |
| 1-6 | Switch weapon (AR/SMG/Marksman/Sniper/Shotgun/Sidearm) |
| Shift | Sprint (drains stamina) |
| Space | Jump — land while holding to bunny-hop |
| C | Slide (while sprinting) |
| Q / E | Lean left / right |
| Z | Dive-to-prone (while sprinting) |

### Automated smoke test

```bash
npm run test:smoke
```

Headless Chromium (Playwright) deploys the game, sprints, fires, reloads, switches
weapons, and asserts the scene renders with zero console errors. Requires
`npx playwright install chromium` once.
